# Novel Writing（小说写作台）

[![version](https://img.shields.io/badge/version-2.13.0-blue)](https://github.com/vrphu/novel-writer-studio/releases/tag/v2.13.0)
[![Obsidian](https://img.shields.io/badge/Obsidian-%E2%89%A51.5.0-7c3aed)](https://obsidian.md)
[![license](https://img.shields.io/badge/license-MIT-green)](LICENSE)

> 本地优先的中文小说写作工作台

一个面向中文长篇创作者的 Obsidian 插件：把「卷章结构、设定库、大纲、情节编排、时间-空间双线、灵感便签、批注、码字统计」收进一个面板，同时把正文本身完整交还给你 —— 插件只做装饰层标记，**不改写你的任何原文**。

仓库地址：https://github.com/vrphu/novel-writer-studio

---

## 功能总览

### 目录（卷 › 章）
- 卷/章树形目录，卷可重命名、拖拽移动章节
- 每章状态四态切换：草稿 / 写作中 / 待修订 / 已定稿
- 每章目标字数（默认 3000），正文顶部悬浮渐变进度条：当前字数、百分比、还差多少、实时码字速度
- 卷级统计：章节数、总字数、总目标、完成度、状态分布、卷内设定 Top10
- 章节可跨卷移动，绑定关系（元数据、大纲、设定引用）同步迁移

### 设定库（两级体系，md 即数据源）
- **6 大类**：世界观总纲 / 人物库 / 角色关系库 / 地理势力库 / 力量或规则库 / 剧情大纲+伏笔库（+ 独立自定义）
- 每条设定 = `设定/<库>/<名称>.md`，frontmatter 存元数据，正文由你自由书写
- 正文提及自动着色：**有颜色** → 彩色加粗；**无颜色** → 加粗 + 倾斜 + 下划线
- 悬停显示设定内容预览，点击直接跳转到设定文件
- **📍 出场章节自动统计**：设定笔记末尾自动生成统计表（共 N 次 · M 章，每章出场次数 + 可点击跳转），随正文修改自动刷新，不碰用户手写内容
- 设定文件改名/改属性/删除 → 统计自动同步（读文件，不依赖缓存）



### 大纲 · 情节 · 双线
- **大纲**：11 类模板（总纲/卷纲/章纲/场景卡/伏笔/时间线/主题等），创建即落盘为 `大纲/<标题>.md`
- 面板里的绑定/解绑、改备注、改类型会**实时同步回大纲文件正文**，你手写的内容原样保留
- **情节编排**：四阶段（开端 → 发展 → 高潮 → 结局）+ 绑定角色 + 章节范围 + 标签颜色
- **多轨时间/空间/情绪线**：三轴独立开关、可建多条轨并行、每条轨可整条绑定人物/情节、轨可重命名

### 灵感 · 批注
- 灵感文件化：每条灵感 = `灵感/<标题>.md`，frontmatter 记录状态（待定/采用/放弃）与绑定对象
- 批注系统：选中文字右键「添加批注」，原文零改动（浅黄底 + 点状下划线），悬浮查看、表格管理、点击跳转

### 专注 · 统计
- 番茄钟：任意分钟输入（1–600）
- **禅模式**：折叠侧边栏 + 全屏 + 版心 44em，7 套壁纸（低刺激深色 / 纸白）
- 音效分离：**打字音效**（机械键 / 轻柔 / 打字机） 与 **背景音**（雨 / 滴 / 泡泡 / 白噪）独立开关
- 打字模式：当前段高亮，前后段渐淡
- 数据中心：84 天热力图、14 天明细（字数 / 码字时长 / 专注时长 / 均速）、累计统计
- 每章统计：速度 / 码字时长 / 专注 / **偷懒时间**（打开时长 − 实际敲字时长）/ 设定分类统计 / Top10
- 500 字行右里程碑 🎯

## 安装

### BRAT（推荐，可自动更新）
1. 安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件并启用
2. 设置 → BRAT → Add Beta plugin → 输入 `vrphu/novel-writer-studio`
3. 启用「小说写作台」；后续有新版本可在 BRAT 内一键更新

### 手动安装
1. 从 [Releases](https://github.com/vrphu/novel-writer-studio/releases/latest) 下载 `main.js` / `manifest.json` / `styles.css` 三个文件
2. 放入你的 Vault：`<你的库>/.obsidian/plugins/novel-writer-studio/`
3. 在 Obsidian 设置 → 第三方插件中启用「小说写作台」

### 命令面板
| 命令 | 作用 |
|---|---|
| 打开小说写作台 | 打开主面板 |
| 新建卷 / 新建章 | 快速创建结构 |
| 同步设定库文件 | 设定文件 ↔ 索引双向同步 |
| 搜索设定库 / 搜索角色 | 模糊检索设定 |
| 生成待查待改清单 | 汇总正文标记 |
| 同步出场章节统计 | 手动刷新设定统计表 |

## 数据说明

- 所有数据都以**库内 Markdown 文件**为唯一事实源：设定、大纲、灵感都是普通笔记，frontmatter 存元数据
- `data.json`（插件设置与索引缓存）保存在插件目录，已加入 `.gitignore`，不入库
- 完全本地优先，无网络请求，无账号依赖

## 开发

纯 CommonJS 单文件实现，无需构建链 —— 改 `main.js` 后重启 Obsidian 即生效。

```
novel-writer-studio/
├── main.js        # 插件主逻辑
├── manifest.json  # 插件元信息
├── styles.css     # 样式
├── versions.json  # 版本 ↔ 最低 Obsidian 版本索引
├── README.md
├── LICENSE        # MIT
└── .gitignore     # 排除 data.json 等运行期数据
```
